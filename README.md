This program was created with the Java language with JAI, JRE, JDK 6 GUI implementation. This program converts matrix files, JPEG to Bitmap, or JPEG 2000,
to save memory, etc. Check output screenshots for further knowledge. Thank You.

like the 2 JAI codec, etc. And the swing default library. Be advised these are really old softwares, and extremely hard to setup and run on a local computer. 

a separate output folder is there were the 4 output files are generated and saved. screenshots are also provided of the gui, and terminal etc.
